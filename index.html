Worst-case latency on an unrelated endpoint dropped from about 29 s to 0.124 s, measured against a stopped Postgres container.

Hardened containers: non-root, read-only root filesystem, all capabilities dropped, no-new-privileges, pinned digests, database password as a Docker secret. A CI workflow asserts each property, and each check was proven to fail on a deliberate break.
